# ATS (Applicant Tracking System) Optimization — Best Practices

When evaluating a resume against a job description for ATS compatibility:
- Flag if key required skills from the JD are missing verbatim from the resume, even if a close synonym is present (ATS keyword matching is often literal)
- Note if the resume's skill terminology differs from the JD's (e.g. resume says "React" but JD says "React.js" or "ReactJS") — recommend matching the JD's exact phrasing
- Identify any required skills mentioned only in a "Projects" or "Education" section but not in "Skills" or "Experience" — ATS systems often weight these sections differently
- Flag overly generic bullet points that lack specific technical keywords an ATS would scan for
- Keep this analysis separate from the human-readable match summary — ATS concerns are about literal keyword presence, not overall qualification
